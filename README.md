## 🚀 What is ShipSpace?

**ShipSpace** is a dedicated platform for technical builders—Indie Hackers, Side-Project Developers, and Founders—who want to share their journey through "Project Updates." 

Unlike traditional social media, ShipSpace treats every post as a **"Ship"** pinned to a persistent **"Project"** entity. This creates a transparent, historical log of your building progress, emphasizing real work over superficial engagement.

## ✨ Key Features

- **Project-Centric Socializing:** All updates are tied to a project historical log.
- **Proof of Work:** Gain reputation through consistent shipping and technical validation.
- **Builder-First Feed:** Algorithmic curation that favors high-signal technical content.
- **Gamified Progression:** Earn "ShipScore" and level up your rank from *Docked* to *Fleet Admiral*.
- **Tech Stack Personalization:** Discovery based on the languages and frameworks you actually use.

## 🛠️ Technology Stack

- **Frontend:** Next.js 14 (App Router)
- **Backend:** Supabase Edge Functions (Deno/TypeScript)
- **Primary Database:** PostgreSQL 16 (Supabase)
- **Personalization Engine:** Spring Boot 3.2 & MongoDB
- **Storage:** Cloudflare R2 (Private & Secure)
- **Auth:** GitHub OAuth 2.0 via Supabase

## 🏁 Getting Started

### Prerequisites
- Java 17+
- Node.js 18+
- Maven 3.6+
- Docker (for local Supabase)

### Quick Start
1. **Clone the repo:**
   ```bash
   git clone https://github.com/SamppurnaTH/ShipeSpace.git
   cd ShipeSpace
   ```
2. **Environment Setup:**
   Refer to the [Deployment Guide](docs/15-Deployment_Environment_Guide.md) for local configuration.
3. **Run Locally:**
   ```bash
   mvn spring-boot:run
   ```
